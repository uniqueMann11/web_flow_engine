Plain definition

What is a vector embedding?

Definition

A vector embedding is a numerical representation of data—text, image, audio, or other content—converted into a list of floating-point numbers (a vector) that captures its semantic meaning. Each coordinate in the vector represents abstract features learned by a machine learning model, so that similar concepts occupy nearby positions in a high-dimensional space. This mathematical encoding enables computers to compare meaning at scale, making vector embeddings the core building block for semantic search, retrieval-augmented generation, recommendation systems, and clustering.

Concept walkthrough

Embedding in action

The same five-step pipeline animating in the signature panel above, applied to your own documents.

STEP 1

Text input

A sentence or phrase, like 'the cat sat on the mat,' is fed into an embedding model.

STEP 2

Model encodes

The model analyzes word order, synonyms, and context, producing a list of numbers like [0.12, -0.45, 0.89, ...].

STEP 3

Vector produced

The output is a high-dimensional vector—often 768 or 1536 dimensions—representing the meaning.

STEP 4

Matched by distance

Cosine similarity or dot product measures how close this vector is to other vectors in the database.

STEP 5

Semantic retrieval

The closest vectors return as results, finding content that means the same thing even with different words.

Why it matters

What is a vector?

A vector embedding is a list of numbers — a mathematical representation — that captures the meaning of a piece of text, an image, or any data. Instead of storing words like 'cat' and 'dog', a model converts them into points in space where similar meanings sit close together.

VISUAL EXAMPLE

Embeddings in action

  • The word 'king' becomes a vector like [0.2, 0.7, -0.1, 0.4, ...]
  • The word 'queen' becomes a vector like [0.3, 0.8, -0.2, 0.5, ...]
  • These two vectors are 'close' in the embedding space because their meanings are similar
  • A vector for 'apple' (fruit) sits near 'banana' but far from 'apple' (company)
  • A diagram would show three clusters: fruits, companies, and animals — each cluster grouping related meanings

How it works

Process

STEP 01the input

Text to numbers

+
A pre-trained embedding model, like OpenAI's text-embedding-3-small, takes your text and outputs a fixed-length vector — typically 256 to 1536 numbers.
STEP 02the space

Semantic proximity

+
Vectors live in a high-dimensional space. The distance between two vectors (cosine similarity) measures how similar their meanings are — closer means more related.
STEP 03the database

Vector search

+
A vector database indexes these embeddings. At query time, it converts your question into a vector and finds the nearest neighbors — the most semantically relevant documents.
STEP 04the output

Retrieval result

+
The system returns the original text chunks whose vectors are closest to the query vector, enabling accurate retrieval without exact keyword matching.

FAQ

Frequently asked questions

What exactly is a vector embedding?
A vector embedding is a list of numbers that represents the meaning of a piece of data — text, image, or audio — in a high-dimensional space. Similar meanings produce vectors that are close together, enabling semantic search.
How is an embedding different from a keyword?
A keyword is an exact word that must match literally. An embedding captures meaning, so 'car' and 'automobile' will have similar vectors even though they are different strings. This is why embeddings power semantic search.
How many numbers are in a typical vector?
Modern embedding models output vectors with 256 to 1536 dimensions — that is, 256 to 1536 numbers. Higher dimensions capture more nuance but increase storage and compute cost.
Can I create my own embedding model?
You can fine-tune an existing embedding model on your domain, but most applications use a pre-trained model from OpenAI, Cohere, or sentence-transformers. Fine-tuning is only needed for highly specialized vocabularies.
What is cosine similarity?
Cosine similarity measures the angle between two vectors; it ranges from -1 (opposite meaning) to 1 (identical meaning). It is the most common metric for comparing embeddings because it ignores vector length and focuses on direction.
