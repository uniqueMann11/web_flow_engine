Plain answer

What is a system prompt?

Definition

A system prompt is a set of instructions or context provided at the beginning of an LLM conversation that defines the model's behavior, tone, constraints, and capabilities. It acts as a persistent directive that shapes every response, ensuring consistency, alignment with user goals, and safety guardrails without requiring model retraining.

FAQ

Frequently asked questions

What is a system prompt?
A system prompt is a block of instructions that sets the initial context and behavior for an LLM. It defines the model's role, constraints, tone, and rules for generating responses, making it the primary tool for shaping output quality and consistency.
How is a system prompt different from a user prompt?
A system prompt is set by the developer and remains constant across a conversation, while a user prompt changes per interaction. The system prompt provides overarching instructions, whereas user prompts are the specific queries the model responds to. Both are essential for controlled LLM behavior.
Can system prompts prevent hallucination?
System prompts can reduce hallucination by instructing the model to stay within certain boundaries or cite sources, but they do not eliminate it entirely. Grounding with retrieved information (RAG) or using guardrails is often needed for critical applications.
